# Automated Geometric Imperfection Modelling and Nonlinear Analysis of Circular Hollow Sections (CHS)


** Research Internship under the guidance of Dr. Meng Xin, National University of Singapore (NUS), Singapore**

---

##  Project Overview

This project focuses on the development of an automated computational framework for generating and analysing controlled **three-dimensional geometric imperfections in Circular Hollow Sections (CHS)** using **Python and ABAQUS**.

A major component of the work was the **explicit mathematical modelling of a sinusoidal geometric imperfection** on the initially perfect CHS geometry. The sinusoidal imperfection equation was formulated to explicitly incorporate and control variations in the **longitudinal waves, circumferential waves, and imperfection amplitude**. This allowed different three-dimensional imperfection patterns to be systematically generated by varying the governing parameters.

The mathematical formulation was subsequently implemented using Python and integrated with an ABAQUS finite element model. The developed Python framework automatically extracts nodal coordinates from an ABAQUS `.inp` file, converts the coordinates from Cartesian to polar form, evaluates the sinusoidal imperfection at every node, modifies the radial coordinate, and converts the modified coordinates back into Cartesian coordinates.

The resulting imperfect geometry is automatically written into a new ABAQUS input file and can be directly analysed using **Static Riks analysis** to investigate nonlinear structural behaviour and buckling response.

The generated numerical simulation data were subsequently used for **machine learning model training**. The developed geometric imperfection modelling approach was also extended from conventional steel models toward **additively manufactured (3D-printed) materials**.

# 🎯 Project Objectives

The major objectives of this research were:

- Develop an explicit mathematical formulation for three-dimensional sinusoidal geometric imperfections in CHS.
- Incorporate independent variations in:
  - Longitudinal waves
  - Circumferential waves
  - Imperfection amplitude
  - Phase angle
- Implement the mathematical imperfection formulation using Python.
- Develop an automated procedure for modifying ABAQUS finite element geometries.
- Extract nodal coordinates directly from ABAQUS `.inp` files.
- Transform nodal coordinates from Cartesian to polar coordinates.
- Apply the prescribed sinusoidal radial imperfection to every node.
- Convert the modified coordinates back to Cartesian coordinates.
- Automatically generate imperfect ABAQUS input files.
- Generate node-level imperfection data in CSV format.
- Visualize and verify the generated three-dimensional imperfection geometry.
- Perform nonlinear Static Riks analysis on imperfect CHS models.
- Generate numerical simulation datasets through automated FE modelling.
- Train machine learning models using the generated numerical data.
- Extend the geometric imperfection modelling framework toward additively manufactured materials.
